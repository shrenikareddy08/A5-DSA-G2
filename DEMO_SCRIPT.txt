BEST VIVA POINTS
----------------
1. The user interacts with text problems, not with HEFT internals.
2. Every request becomes a Task object dynamically.
3. Task requirements come from workload analysis and operation type.
4. The DAG prevents dependent operations from running early.
5. HEFT-style upward rank prioritizes work that controls remaining pipeline.
6. Resource compatibility prevents impossible CPU/RAM placements.
7. Independent tasks run in parallel.
8. Actual runtime is measured and fed back into the runtime model.
9. Results are produced by real manually implemented algorithms.
10. java.util.* is not used inside the algorithm/scheduling engine.
